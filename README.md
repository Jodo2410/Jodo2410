### Hey, I'm Jonas 👋

I build things that probably didn't need to exist — and then I ship them anyway.

Mostly poking at **Go**, **C#**, **TypeScript**, and whatever language a project happens to drag me into. I like small, sharp tools, weird side-projects, and making games/servers/PCs do things they weren't quite asked to do.

---

#### 🛠️ Things I've built

- 🧱 **[PrefabBuilder](https://www.curseforge.com/hytale/mods/prefabbuilder)** — my Hytale mod for Adventure Mode prefab building. Place a prefab, hand over the resources, watch your structure grow block by block — no more creative-mode cheating. Includes an import system, admin config editor, and a (beta) multiplayer sync so friends can build the same structure together. **12.9K+ downloads on CurseForge** 🎉
- 🧩 **[Code-Challenge](https://github.com/Jodo2410/Code-Challenge)** — a growing collection of coding challenges wired up as a VS Code extension database.
